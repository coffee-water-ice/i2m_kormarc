# legacy_2025_code/

`1215_main.py`는 통합 이전 "2025년 코드"(원래 위치: `I2M 통합 코드/통합 이전 코드/2025년 코드/1215_main.py`,
i2m_kormarc 저장소 바깥의 형제 폴더)의 **바이트 단위 복사본**이다.

## 왜 여기 있는가

`pages/2_2025년_코드_원본.py`(새 통합 파이프라인과의 결과 비교 페이지)가 이 파일을 그대로
실행한다. 로컬에서는 원본 위치(`통합 이전 코드/2025년 코드/1215_main.py`)가 있으면 그쪽을
우선 실행하지만, Render/Streamlit Cloud 같은 배포 환경은 이 git 저장소만 클론하므로
원본 위치 자체가 존재하지 않는다 — 배포 환경에서 이 페이지가 동작하려면 저장소 안에
사본이 있어야 한다.

## 절대 원칙

- **이 파일은 절대 수정하지 않는다.** 원본(1215_main.py, 5284줄)과 100% 동일해야 한다.
  (`.gitattributes`에 `-text`로 등록해 git이 줄바꿈을 임의로 바꾸지 못하게 고정해 뒀다.)
- 원본이 바뀔 일은 없는 것으로 간주한다(비교 기준선으로 고정된 레거시 코드). 만약 원본이
  수정된다면, 이 사본도 수동으로 다시 복사해 동기화해야 한다.
- 다른 코드에서 이 파일을 import하지 않는다 — `pages/2_2025년_코드_원본.py`가
  `importlib`로 필요할 때만 동적으로 로드한다.
